# Design documents

This directory holds design documents that span more than one package, such as a cross-cutting
wire format or a feature that touches the backend and the frontend.

- Name a file for its subject in `kebab-case`, e.g. `list-filter-wire.md`.
- A design document for one scope goes in that scope's `DESIGN.md`, not here.
- Use the `design-doc` skill (`.agents/skills/design-doc/SKILL.md`) for the format: purpose,
  tiered goals, non-goals, frozen contracts, and the rationale.
- Use the `feature-design` skill to interview the user before you write one.
